# Mid Evaluation Pack

This directory contains the evaluator-facing material for the CS5013 mid-evaluation.

## Deliverables

- `principles_and_practices.pdf` - the Moodle submission; exactly three pages.
- `principles_and_practices.docx` - editable source for last-minute team details.
- `architecture.svg` and `architecture.png` - the complete portal-to-solver system flow.
- `EVALUATION_RUNBOOK.md` - two-minute script, live demonstration order, viva questions, and modification drills.

## Recommended evaluation flow

1. Open the live [published results](https://cs5013-project-portal.vercel.app/results).
2. Keep `architecture.png` open as the system-flow soft copy.
3. Explain the pipeline with the two-minute script in `EVALUATION_RUNBOOK.md`.
4. Inspect EE3110 in the live result: its slot B explanation exposes the unavoidable student-conflict contribution of 3 and classifies alternatives.
5. If asked to modify code, follow the six-step safe workflow in the runbook: locate ownership, run the nearest test, make one change, add one assertion, run the focused test, then run the full suite.

The showcase contains only synthetic identifiers and preferences. During the evaluation, use only the AI tool allowed by the course instructions.
