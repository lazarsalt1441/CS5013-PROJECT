# Prompt Review Checklist

Before using an AI-generated response:

1. **Context:** Does the prompt name the current module, data assumptions, and relevant files?
2. **Objective:** Is there one testable outcome?
3. **Constraints:** Are language, APIs, scope limits, and negative instructions explicit?
4. **Examples:** Are input/output examples included when the format matters?
5. **Uncertainty:** Does the prompt require assumptions to be stated rather than invented?
6. **Security/privacy:** Does it exclude credentials and personally identifiable student data?
7. **Verification:** Does it request tests, commands, or observable acceptance criteria?
8. **Review:** Has a human checked correctness, maintainability, and consistency with the design?

Prompt revisions and rejected outputs stay in the log so the repository records reasoning, not only the final answer.
